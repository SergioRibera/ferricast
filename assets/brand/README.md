# brand assets

Read `BRAND.md` for the full guide. Quick pointers:

| Need | File |
| --- | --- |
| App icon · Linux | `icon/linux/hicolor/scalable/apps/ferricast.svg` (+ PNG sizes alongside) |
| App icon · Windows | `icon/windows/ferricast.ico` |
| App icon · macOS | `icon/macos/ferricast.iconset/` → pack with `iconutil -c icns` on a Mac |
| App icon · web / HTML | `icon/favicon/` (ships favicon.svg, favicon.ico, PNG sizes, webmanifest, head snippet) |
| Tray icon | `icon/tray/ferricast-tray-mono.svg` (template, tints with currentColor) |
| Logo in docs | `lockup/ferricast-horizontal.svg` or rendered PNGs in `png/` |
| Symbol only | `symbol/ferricast-symbol.svg` (use `-small.svg` under 32 px) |
| Palette | `palette.json` |
| Linux .desktop template | `ferricast.desktop` |
